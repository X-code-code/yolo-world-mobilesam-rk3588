# Changelog

All notable project changes are recorded here.

## 0.1.0 - 2026-08-25

- Publish the verified RK3588 runtime, live dynamic-prompt UI, three-core NPU scheduling, tests and board benchmarks.
- Add a reproducible RKNN Toolkit2 2.3.2 conversion workflow with input and output SHA-256 manifests.
- Add an integrity-checking downloader for model assets published through GitHub Releases.
- Publish only model artifacts whose redistribution basis is documented; keep models with unresolved or additional source-distribution obligations out of public assets.
