# v0.1.0 — RK3588 dynamic target detection and MobileSAM model package

This is the first reproducible project release for LubanCat 4 / RK3588.

## Runtime and conversion source

- Dynamic runtime text prompts through CLIP Text and YOLO-World V2-S.
- YOLO bbox to MobileSAM target mask.
- Live web and OpenCV camera UIs.
- Explicit three-core RK3588 NPU scheduling.
- Pinned ONNX downloader and unified RKNN Toolkit2 2.3.2 conversion profiles.
- Machine-readable source, conversion, calibration and output SHA-256 provenance.
- 57 offline/host unit tests plus a release-content scan.

## Model asset

`mobilesam-rk3588-fp16-v0.1.0.zip`

```text
bytes   49,833,372
sha256 6b979c5e12201e141197fab62633f160d3708a3d4aa5a03868fa916edc5a9685
```

The archive contains the verified RK3588 FP16 MobileSAM encoder and decoder, individual checksums, provenance, the Apache License 2.0, the model notice and a usage README.

After cloning this tag, download, extract and verify it with:

```bash
python3 scripts/download_models.py
```

The CLIP and YOLO RKNN files are not assets in this release. The CLIP model card does not state an explicit weight redistribution license; the GPL-3.0 YOLO binary would require a complete corresponding-source bundle. Their verified identities remain documented, and `conversion/` generates them locally from pinned official ONNX inputs.

## Board evidence

The five locally converted RKNN hashes matched the deployed board files. On the verified RKNNLite 2.3.2 / driver 0.9.8 setup, the three-core static full-pipeline benchmark reached 7.42 wall FPS versus 4.83 serial-auto FPS with consistent bbox, confidence and mask hashes. See [the benchmark method and raw de-identified record](../BENCHMARKS.md).

Model assets have their own upstream terms; the repository-level Apache-2.0 license does not automatically cover every model. See [model artifact notices](../../MODEL_LICENSES.md).
